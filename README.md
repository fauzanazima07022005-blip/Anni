# Orang Favoritku ♡

Hadiah digital kecil. Buka `index.html` di browser, selesai.

- **Foto**: timpa `assets/images/photo1.jpg` sampai `photo6.jpg` (nama file harus sama).
- **Teks**: ada di `index.html` dan `script.js` (surat ada di `LETTER`).
- **Warna**: ubah variabel di `:root` dan tema gelap di `style.css`.
- **Musik**: taruh `assets/audio/song.mp3`, tombol ♪ di layar pembuka akan memutarnya.
- **WhatsApp**: ganti `WA_NUMBER` di paling bawah `script.js` (format 62812..., tanpa 0, + atau spasi).
- **QR**: otomatis mengarah ke link halaman, jadi baru bisa discan kalau sudah online (GitHub Pages, Netlify, dll).
